# Hotel Data Analysis Project

## Project Overview

This project analyzes hotel booking data to identify trends, clean raw datasets, and extract business insights that can support operational and strategic decisions.

The project includes data exploration, preprocessing, handling missing values, outlier treatment, and analytical tasks using Python.

---

## Objectives

- Explore hotel booking datasets
- Perform data cleaning and preprocessing
- Handle missing values and invalid records
- Detect and manage outliers
- Analyze booking patterns and business metrics
- Generate meaningful insights from hotel data

---

## Dataset Information

The project uses multiple datasets:

- dim_date.csv
- dim_hotels.csv
- dim_rooms.csv
- fact_aggregated_bookings.csv
- fact_bookings.csv

---

## Tools and Technologies

- Python
- Pandas
- NumPy
- Jupyter Notebook

---

## Project Workflow

### 1. Data Import and Exploration

- Loaded booking datasets
- Examined columns and data structure
- Performed initial exploration

### 2. Data Cleaning

- Removed invalid guest records
- Handled missing values
- Checked and treated outliers
- Filtered inconsistent records

### 3. Data Analysis

Performed analysis on:

- Property performance
- Booking patterns
- Capacity utilization
- Revenue metrics
- Customer trends

---

## Key Insights

- Identified booking patterns across properties
- Detected invalid and inconsistent records
- Improved data quality through cleaning
- Generated insights useful for business decision-making
